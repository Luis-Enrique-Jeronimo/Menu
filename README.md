# MENU CAFES COYO

El siguiente menú es un programa sencillo con la finalidad que el cliente tenga visualización del menú al igual que el usuario final, incluyendo que el cliente tenga acceso exclusivamente para el a un panel donde se incorporo el sistema CRUD para cada grupo de alimentos, articulos del menú y de las promociones.

## Las tecnologías utilizadas fueron:

- FrontEnd

    - HTML
    - CSS 
    - Java Script 

- Backend
        
    - JSON
    - Node JS
